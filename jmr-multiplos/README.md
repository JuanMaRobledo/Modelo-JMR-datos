# Biblioteca de JMR múltiplos

`biblioteca.json` contiene exclusivamente el catálogo y los expedientes de **JMR múltiplos**, generados con `scripts/exportar-biblioteca.mjs` de `JuanMaRobledo/JMR-M-ltiplos`. No utiliza DCF ni comparte catálogos o motores con V2 o Floyd.

La biblioteca inicial conserva ORCL y su solicitud expresa, controles y salvedades. No se crea ni actualiza ninguna valoración económica con esta migración. Una publicación técnica no equivale a aprobación del propietario.

Actualizar y publicar solo esta biblioteca en `main` no requiere desplegar la app. No conectar este repositorio a Vercel. El código y las instrucciones de exportación viven en el repositorio propio de la aplicación. El repositorio es público: no incluir documentos privados ni credenciales.
