# Gemini CLI · rutas y protección del repositorio compartido Modelo-JMR-datos

**Repositorio compartido:** aquí conviven publicaciones de distintos proyectos. No asumir que el AGENTS.md histórico de la raíz es el contrato de JMR V2. Antes de cualquier modificación determinar explícitamente el proyecto indicado por el usuario.

- **JMR V2:** exclusivamente `jmr-v2/`, usando el contrato vigente y `GEMINI.md` de `JuanMaRobledo/Modelo-JMR-V2`. La instrucción específica del directorio `jmr-v2/GEMINI.md` define cómo publicar.
- **JMR Múltiplos:** carpeta `jmr-multiplos/`, motor/contrato en `JuanMaRobledo/JMR-M-ltiplos`, **solo a solicitud expresa**.
- **Floyd / archivo histórico:** otras rutas de este repositorio. No modificar en tareas de V2 ni mezclar contratos, modelos o bibliotecas.
- Nunca modificar varias bibliotecas en una misma tarea salvo instrucción expresa y controles separados.
- Nunca imprimir ni guardar en Git credenciales, PAT, tokens o archivos privados; **este repositorio de datos es público**.

Para tareas de JMR V2, utilizar la copia de trabajo del repo principal y seguir `CONTENIDOS.md` y el contrato v1.5.5 o su sucesor autorizado. No editar ni fusionar sobre `main` directamente en ejecución autónoma: crear rama y PR con pruebas, esperar instrucciones del propietario para la fusión/publicación.
